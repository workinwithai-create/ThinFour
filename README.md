# ThinFour

Four-bar live thinning desk for bedroom producers and AI-music finishers.

Generators keep every chair playing. Session players thin four live bars so the next section hits with air and clarity.

Live samples only — FluidR3 acoustic grand, upright bass, nylon guitar, trumpet, violin, and an acoustic kit. No oscillators. Audio never leaves the tab.

## Distinct from the rest of the line

| Tool | Job |
| --- | --- |
| MuteEight | Make the drop feel different by taking things out |
| LiftTwo | Two-bar production lift into the hook |
| TagFour | Four-bar last-line tag after the money chorus |
| PreEight | Eight-bar musical climb before the hook |
| AfterHook | Eight bars after the hook |
| EndEight | Last eight bars of the record |
| LastHook | The money last chorus |
| **ThinFour** | Four bars of *thinning* so the next section has air |

Yesterday’s ships and the named exclusions (TagFour, ModEight, LiftTwo, PreEight, AfterHook, EndEight, LastHook) are different jobs. ThinFour is density control in the middle of a form, not a tag, not a lift, not a mute-for-drop.
